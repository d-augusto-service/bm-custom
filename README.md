# B’M Custom — versão simples (GitHub Pages)
Site estático: sem servidor, sem painel. O carrinho fica no navegador e o pedido segue por WhatsApp.
- **Ver no computador:** abra `index.html` com duplo clique.
- **Produtos:** gere-os com `node scripts/exportar-site-simples.js "pasta-deste-site"` na loja completa (lê o painel e copia as fotos), ou edite `js/produtos.js`.
- **Entrega, zonas e WhatsApp:** `js/dados.js`.
- **Imagens:** ver `MANUAL_DE_IMAGENS.md` (as de produtos são copiadas pelo comando acima).
- Limites: o stock é o do ficheiro e não baixa sozinho; o pagamento combina-se por WhatsApp.
